## V1.0 生产可用版（P0 上线必做）
### 一、架构核心风险修复
1. **Django SSE 异步透传改造**
   - 涉及模块：AI 测试平台（Django）、联动调用链路
   - 改造内容：Django 切换 ASGI 模式，使用 `httpx.AsyncClient` 异步转发 SSE 流，替换同步 `requests.iter_lines()` 方案
   - 验收标准：
     - 单 worker 支持并发 SSE 连接数 ≥ 100
     - 流式响应延迟 ≤ 200ms
     - 连接异常时自动释放资源，不阻塞普通接口

2. **工作流执行异步化改造**
   - 涉及模块：底座工作流引擎、Django 任务网关
   - 改造内容：工作流接口改为异步提交，立即返回 task_id；执行状态通过轮询/SSE/Webhook 同步
   - 验收标准：
     - 工作流接口响应时间 ≤ 200ms，不受执行时长影响
     - 支持任务取消、进度推送、断点续跑
     - 长耗时任务（>30s）不占用 HTTP 连接

### 二、安全体系补全
3. **跨服务统一鉴权体系**
   - 涉及模块：底座 Auth 模块、Django 网关、MCP 工具回调
   - 改造内容：
     - 统一 JWT 身份体系，Django 转发请求时透传用户 Token
     - 新增服务级签名鉴权，确保仅授权业务方可调用底座
     - 底座回调 Django 工具接口时携带服务 Access Token，双向校验
   - 验收标准：
     - 闭环解决原文档「认证透传」「MCP 回调鉴权」两个已知问题
     - 未授权服务无法调用底座与业务工具接口
     - 用户身份可在全链路透传且不可伪造

4. **AI 原生安全防护**
   - 涉及模块：底座 LLM 入口、沙箱模块
   - 改造内容：
     - 新增输入检测中间件：Prompt 注入检测、敏感词过滤、越权指令拦截
     - 新增输出内容审核：敏感信息、恶意内容打标拦截
   - 验收标准：
     - 常见 Prompt 注入攻击拦截率 ≥ 90%
     - 敏感数据（密钥、内网地址）不会随输出泄露

5. **代码沙箱容器级加固**
   - 涉及模块：底座沙箱模块
   - 改造内容：从进程级隔离升级为一次性 Docker 容器隔离，执行后立即销毁
   - 验收标准：
     - 强制限制 CPU、内存、执行时长、磁盘读写
     - 默认禁止内网访问，仅开放白名单外部地址
     - 无持久化存储，沙箱逃逸风险可控

### 三、数据一致性保障
6. **任务状态最终一致机制**
   - 涉及模块：Django 任务表、底座工作流/任务模块
   - 改造内容：
     - 状态变更以底座为准，Django 仅同步存储
     - 新增定时补偿任务，轮询超时任务并修正状态
     - 关键状态变更支持 Webhook 回调 + 失败重试
   - 验收标准：
     - 网络抖动、服务重启后，任务状态最终一致
     - 无「底座已完成、平台显示运行中」的永久不一致

7. **全接口幂等性改造**
   - 涉及模块：底座所有写接口、配额扣减、工具调用
   - 改造内容：强制要求 `idempotency_key` 幂等键，相同请求重复调用仅执行一次
   - 验收标准：
     - LLM 调用、配额扣减、任务创建重复调用无副作用
     - 重试机制不会导致重复扣费、重复执行

### 四、可观测性闭环
8. **全链路 Trace 透传闭环**
   - 涉及模块：Django、底座、LLM 调用、工具回调
   - 改造内容：统一 Trace 规范，前端生成 trace_id，全链路透传至所有子调用
   - 验收标准：
     - 单条 Trace 可串联「前端→Django→底座→LLM→工具回调→沙箱」全流程
     - Django 侧数据库、Celery 任务均纳入追踪

9. **基础告警体系搭建**
   - 涉及模块：Prometheus + Alertmanager
   - 改造内容：配置核心指标告警规则，分级通知
   - 验收标准：
     - 覆盖服务宕机、错误率>10%、熔断触发、配额超限四类核心场景
     - 告警分级：紧急（短信/电话）、重要（即时通讯）、一般（日志）

## V1.1 稳定增强版（P1 公测前完成）
### 一、架构边界与扩展性优化
10. **RAG 能力统一下沉底座**
    - 涉及模块：底座记忆模块、Django 知识库模块、Milvus
    - 改造内容：
      - RAG 检索、文档向量化能力全部收敛到底座，对外提供标准 API
      - Django 仅保留业务文档元数据管理，检索能力统一调用底座
      - Milvus 统一由底座维护，按命名空间隔离业务知识库与 Agent 记忆
    - 验收标准：
      - 解决原文档「数据库重复、Milvus 各一套」的问题
      - 新增业务方无需重复建设 RAG 能力
      - 向量存储运维入口统一

11. **配置中心与服务发现接入**
    - 涉及模块：底座、Django 配置层
    - 改造内容：
      - 接入配置中心（Nacos/Apollo），熔断、限流、模型配置动态生效
      - 支持服务发现，底座多实例负载均衡，移除写死的 localhost 地址
    - 验收标准：
      - 参数修改无需重启服务
      - 底座支持水平扩容，自动负载均衡

### 二、系统韧性增强
12. **多级熔断与精细化限流**
    - 涉及模块：底座韧性模块、Django 熔断器
    - 改造内容：从全局熔断升级为「服务级→接口级→租户级」三级熔断
    - 验收标准：
      - 单个租户异常不影响全局服务
      - 支持按租户维度设置并发数、Token 消耗量限制
      - 超限请求支持排队机制，而非直接拒绝

13. **分级降级策略落地**
    - 涉及模块：底座韧性模块、Django 业务层
    - 改造内容：定义三级降级预案并落地
    - 验收标准：
      - L1：主模型不可用 → 自动切换备用模型
      - L2：底座部分能力不可用 → 关闭非核心功能，核心流程可用
      - L3：底座整体不可用 → 返回友好提示，支持离线兜底功能

### 三、工程化与测试
14. **核心模块测试覆盖**
    - 涉及模块：工作流引擎、ReAct、熔断、限流、鉴权
    - 改造内容：补全单元测试、集成测试、压测
    - 验收标准：
      - 核心模块单元测试覆盖率 ≥ 80%
      - 覆盖 Django→底座全链路、断点续跑、工具回调等核心场景
      - 压测验证 100 并发下系统稳定性

15. **API 契约与版本化规范**
    - 涉及模块：底座 API 层
    - 改造内容：
      - 基于 FastAPI 原生生成 OpenAPI 文档，作为唯一接口契约
      - 明确版本兼容策略：大版本保留旧接口，至少兼容 1 个历史版本
    - 验收标准：
      - 解决原文档「API 版本化兼容策略」问题
      - 接口变更有规范，接入方可提前感知

16. **密钥管理加密化**
    - 涉及模块：底座配置层、LLM 提供商模块
    - 改造内容：接入 KMS/Vault，敏感凭证加密存储，运行时动态解密
    - 验收标准：
      - 配置文件无明文凭证
      - 支持密钥轮转、按租户隔离 API Key
      - 密钥调用全量审计

### 四、多租户能力增强
17. **租户资源队列隔离**
    - 涉及模块：底座工作流调度器
    - 改造内容：按租户划分独立任务队列，避免资源抢占
    - 验收标准：
      - 单个租户大量长耗时任务不影响其他租户响应速度
      - 支持按租户等级分配不同队列资源

## V1.2 SaaS 商业化版（P2 商用前完成）
### 一、计费与运营体系
18. **计费与账单体系**
    - 涉及模块：租户模块、计费中心
    - 改造内容：
      - 支持套餐包 + 按量付费混合模式
      - 按租户统计 Token 消耗、调用次数，生成日/月账单
      - 余额管理、充值、欠费冻结、续费提醒
    - 验收标准：
      - 支持多套餐差异化定价
      - 账单明细可追溯，计费准确无误差

19. **租户自助控制台**
    - 涉及模块：底座运维前端、租户体系
    - 改造内容：开放租户自助管理页面
    - 验收标准：
      - 租户可自助查看用量、管理 API 密钥、配置工具白名单
      - 支持查看账单、提交工单，减少人工运营成本

### 二、合规与治理
20. **数据合规与生命周期管理**
    - 涉及模块：全链路数据存储
    - 改造内容：
      - 定义各类数据留存周期，到期自动清理
      - 支持租户数据导出、注销后彻底销毁
      - 日志、监控中敏感信息自动脱敏
    - 验收标准：
      - 满足基础数据合规要求
      - 租户注销后数据可彻底清除并提供销毁证明

21. **全量审计日志**
    - 涉及模块：底座审计模块、Django 业务层
    - 改造内容：记录所有关键操作，支持检索导出
    - 验收标准：
      - 覆盖登录、配置修改、模型调用、租户变更等关键操作
      - 保留操作人、时间、IP、参数，满足合规追溯要求

### 三、高可用与容灾
22. **基础设施高可用部署**
    - 涉及模块：数据库、缓存、向量库、应用服务
    - 改造内容：
      - PostgreSQL 主从架构 + 读写分离
      - Redis 集群/哨兵模式
      - Milvus 分布式集群部署
      - 应用服务多实例部署，无单点
    - 验收标准：
      - 单实例故障不影响整体服务可用性
      - 服务可用性 ≥ 99.9%

23. **数据备份与容灾方案**
    - 涉及模块：所有持久化存储
    - 改造内容：制定备份策略与容灾预案
    - 验收标准：
      - 数据库每日全量备份 + 增量备份，Milvus 定期快照
      - 明确 RTO/RPO 目标，定期容灾演练
      - 数据损坏可快速恢复
